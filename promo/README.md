# Gauge product film

An auto-playing, Apple-style product film of the Gauge demo in [`demo/`](../demo).
It runs on its own, needs no build step, and works offline once the page is loaded:
the New Jersey map is baked in, and fonts fall back to the system font.

```bash
node promo/tools/serve.mjs      # http://localhost:4610
```

(Opening `promo/index.html` directly also works in most browsers.)

## What it shows (92 seconds, 12 chapters)

| # | Chapter | What happens |
|---|---|---|
| 1 | Cold open | Kinetic type; a starfield condenses into New Jersey's 118 signals |
| 2 | Gauge | Rails draw in, wordmark resolves from blur |
| 3 | Launch | Desktop, dock, cursor, genie-style window open |
| 4 | Signals map | The NJ outline draws, counties fade in, funded companies drop in with ripples |
| 5 | All public signals | Toggle: 42 → 118 likely startups, 24 → 47 towns |
| 6 | Town search | "Princeton" is typed; the camera dives into Aster BioSystems |
| 7 | Evidence card | Facts check in, unknowns stay unknown, program matches flip in, with depth-of-field zooms |
| 8 | Programs | Three program cards cascade in 3D |
| 9 | Pipeline | Form D, SBIR, and NJEDA/CSIT → link → classify → match → alert, with particle flow (counts from a real NJ run) |
| 10 | Alerts | Ready vs. held notifications: automatic only on exact identity |
| 11 | Evidence, not certainty | Facts, inferences, unknowns |
| 12 | Finale | Rails, wordmark, "standard gauge" |

## Player features

| Control | Key | |
|---|---|---|
| Play / pause | Space | Auto-pauses when the tab is hidden |
| Seek | ← → (5s), drag the scrubber | Hover shows time and chapter |
| Chapters | C, `[` `]`, 1–9, 0 | Ticks on the scrubber, jump menu |
| Speed | S | 0.5×, 1×, 1.5×, 2× |
| Captions | K | Voice-over style captions |
| **Explore** | E | Pause and click the live UI: map markers, priority rows, nav, the Already funded / All toggle, and a working town search (try `Camden`, or `Cape May` for the honest "no signal" message) |
| Aspect | A | 16:9, 1:1, 9:16 social cuts (desktop scenes center-crop around the camera; title cards rescale) |
| Sound | M | Optional ambient pad plus UI clicks, typing, and whooshes, generated with WebAudio (no audio files) |
| Presenter notes | N | What to say during each chapter |
| Share | U | Copies a link to the current moment |
| Loop / clean / fullscreen | L / H / F | H hides the controls for screen recording |

URL options: `#t=42` or `#search` (chapter id) start at a moment; `?paused`, `?clean`, and
`?cut=9:16` / `?cut=1:1` are also supported. `window.GaugeFilm` exposes `seek(t)` for scripting.

## Recording a video

1. Open `http://localhost:4610/?clean` in a 1920×1080 browser window, or press F for fullscreen.
2. Start your screen recorder, then press R (restart). The film runs 92 seconds.

For a vertical social cut, use `?clean&cut=9:16` and record a 1080×1920 window.

## Honesty

Every company in the film is one of the demo's fictional companies. The pipeline counts
(11,114 records, 4,346 companies, 1,185 likely startups, 53 ready alerts) come from a
real run on New Jersey public records (see `docs/validation/results/`). The film
deliberately does not reuse the demo's illustrative backtest percentages: the real
backtest did not beat simple baselines yet.

## How it works

- `index.html`: the 1920×1080 stage (desktop, Gauge window, story layers) and player.
- `promo.css`: styles; the Gauge window follows the demo's own styles.
- `promo.js`: `render(t)` sets every animated property from the playhead alone, so any
  moment can be rendered directly. Camera and cursor are keyframe tracks that target
  real UI anchors measured from the layout.
- `map-data.js`: generated by `tools/build-map.mjs` from `us-atlas` and the demo's
  `gauge-data.ts` (run `node promo/tools/build-map.mjs` after changing demo companies).
